# Projeto Integrador Turismo

Aplicação para cadastro e listagem de destinos turísticos, com back-end em Spring Boot e front-end em React.

## Endpoints

| Método | Rota      | Descrição            |
|--------|-----------|------------------------|
| GET    | /destinos | Lista os destinos      |
| POST   | /destinos | Cadastra um destino    |
